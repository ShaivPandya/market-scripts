# OpportunityCandidate Eval Rubric

Score each dimension from 0 to 5.

## trigger_clarity

Does the candidate clearly state what drew attention to this opportunity now?

- 0-1: missing or vague trigger
- 2-3: trigger present but underspecified
- 4-5: concrete, attributable trigger tied to the user or alert context

## why_now

Does the candidate explain why this matters now rather than later?

- 0-1: empty or generic timing language
- 2-3: partial timing rationale
- 4-5: specific why-now tied to catalyst, user intent, or monitor change

## missing_inputs

Does the candidate honestly surface the inputs still needed before a full pressure-test?

- 0-1: omits obvious gaps or pretends the setup is complete
- 2-3: lists some gaps but misses key blockers
- 4-5: specific, actionable missing inputs aligned with triage discipline

## triage_discipline

Does the candidate stay non-actionable and choose the correct triage next_action?

- 0-1: emits actionable language or wrong graduation/research/avoid choice
- 2-3: non-actionable but weak triage routing
- 4-5: correct next_action with no buy/sell/add/short leakage and appropriate graduation restraint

## Judge Total

For automated judge runs, total is capped at 20 and each dimension is scored 0-5.

Pass threshold default: 14.
